# 模块池与组合公式

来源：豆包 A+B+C 框架，经用户关系档案加权修订。所有方案必须由本文件的模块拼装生成。

## 组合公式

**A（核心行为）+ B（场地）+ C（氛围变量）= 一个约会方案**

进阶：链式组合——`先 A1 在 B1，累了转到 A2 在 B2，时间选 C`（一个周末最多两段，禁止三段以上赶场）。

开场句式模板（对她说，低解释成本）：先锁定 A——「今天是想坐着看点什么，还是慢慢逛？」——再给两个 B 选项让她二选一。**只问 A 和 B，C 由执行方直接定，不问。**

## A 池（核心行为）

### 权重 ★★★（平行陪伴型，默认优先）

| 编号 | 行为 | 说明 |
|---|---|---|
| A01 | 阅读/翻书/看图文 | 可各看各的，天然平行 |
| A02 | 放空、看风景、发呆 | 零互动压力，户外首选 |
| A03 | 漫无目的闲逛、缓游 | 节奏由她定 |
| A04 | 各自处理自己的事 | 共处一室各干各的，最典型的"日常数据" |
| A05 | 看展（画/植物/老物件） | 有话题但不强制聊 |
| A07 | 简单品鉴（咖啡/茶/水果） | 低门槛，有轻话题 |
| A08 | 慢慢挑小物件（不一定买） | 花鸟市场/杂货店适用 |
| A10 | 看影像（纪录片/老电影/各自追的剧） | 宅家 fallback，注意是弱档（见 weights.md） |
| A11 | 松弛坐着吃点喝点 | 万能衔接项 |
| A12 | 观察旁人、小动物 | 猫咖/花鸟市场/江边，天然玩闹素材 |

| 编号 | 行为 | 说明 |

| A09 | 手工/拼装/拼图 | 合作但无对视压力，适合理状态好的周末 |

### 慎用池（默认排除）

双人密室、剧本杀、需要持续对视的桌游、需要她社交的多人局、高体力项目（爬山、长时间徒步，除非她状态明确好）、需要提前排练或 Dress Code 的活动。**以上仅在用户明确点名时启用，且需在方案中标注"慎用，观察她反应，随时撤"。**

## B 池（场地）

### 淮南本地分类（搜索时按此映射）

| 类型 | 淮南对应候选 | 搜索关键词 |
|---|---|---|
| 店内-静 | 独立书店、安静咖啡馆、茶室、图书馆阅览区 | `淮南 书店 咖啡馆 茶室 安静` |
| 店内-逛 | 文创杂货店、花鸟市场、绿植店、二手市集、猫咖 | `淮南 花鸟市场 猫咖 杂货` |
| 场馆 | 美术馆、画廊、博物馆、展览（临时展优先） | `淮南 展览 博物馆 美术馆` |
| 户外 | 龙湖公园、舜耕山、淮河/滨江步道、植物园、八公山（轻量段） | `淮南 公园 步道 景点` |
| 移动 | 车内（兜风后停车静坐/看日落） | 不需搜索，随季节选观景位 |
| 家 | 客厅、厨房 | 生活流水主阵地 |

**规则**：每个方案引用的场地必须来自第一步的搜索结果（车内和家除外），附链接。老店和新店穿插给，避免每次都推同一家。

## C 池（氛围变量，由执行方直接定不询问）

- **时间**：清晨人少 / 黄昏光好 / 夜晚灯光 / 雨天（雨天自动切店内）
- **声音**：自带歌单 / 店内原声 / 安静
- **道具**：带书、带零食、带坐垫、耳机分听、保温杯（腰疼天冷可用）
- **规则**：全程沉默优先 / 有感才聊 / 各自选互相浅尝
- **移动**：定点不动 / 缓慢边走边停
- **季节钩子**：当季限定（秋天的舜耕山落叶、冬天的热茶、节日的灯展）——季节钩子权重额外 +1，因为天然自带话题不费设计

## 组合示例（用于校验生成质量，不许照抄）

- A01 + 安静咖啡馆靠窗 + 黄昏
- A13 + 家厨房 + 雨天（生活流水）
- A12 + 花鸟市场 → 链式转 A07 + 旁边茶室
- A15 + 车内 + 日落观景位
- A16 + 家客厅 + 电竞比赛日（接共同梗池）
