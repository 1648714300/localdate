# LocalDate · 本地约会方案生成器

> 不给"去看电影吧"，给的是——"周六下午，去曹庵镇范圩村的草莓棚，一人一个篮子，看哪颗红摘哪颗，出来称重，红颜 70 块一箱四斤。想约就说：'曹庵草莓 12 月开摘，一人一个篮子，摘多少算多少。'"

一个给 AI 助手用的 **Skill**：接一句"约会去哪"，返回 15 个可直接落地、不编造、能立刻发消息邀约的方案；你排一次序，它就学会你的口味。

**一句话安装**（复制给你的 AI 助手，把 URL 换成你的仓库地址）：

```
请将公开仓库 https://github.com/1648714300/localdate 下载并安装为本地 Skill，
然后读 city-packs/huainan/，给我一轮约会方案。
```

没有 pip、没有 API key、没有环境变量。装完就能用。

| 你的处境 | LocalDate 会给什么 |

| "周末又不知道去哪，最后宅家看剧" | 15 个具体到门牌号、价格、时段的方案，直接挑 |

| "给的方案都一个味：吃饭、看电影、逛商场" | 结构强制 7 常规 + 2 少去 + 1 慎用，返场每轮最多 1 个 |

## 它给出来的是这个样子

真实运行的第 9 轮（淮南），原文照抄三条：

> **一块钱坐轮渡过淮河**。去淮上渡口，花一个傍晚，买两张手撕票，站在甲板上三分钟渡到对岸高皇镇，逛一圈乡镇集市再坐回来，回岸正好落日把河面铺成金色。渡口在田家庵淮舜北路，1897 年就有了，5:00-22:00 满员即发，行人 1 元一次；16 点到 19 点光最好。下船去淮滨美食街吃泡菜臭豆腐和现冲藕粉八宝粥。想约就说："带你去坐一块钱的轮渡，三分钟过淮河，回来正好日落。"

> **康溪盛世打台球**。去康溪盛世台球俱乐部星舰店，花一个下午，开一张台打三局，谁输谁摆球，她水平差就先让她开。店在田家庵朝阳街道京澳广场 501-504，人均 16 元，全天开放，评分 4.3。打完在楼下吃碗面。想约就说："打台球去，输的摆球，一小时十几块。"

> **老街看露天电影**。去淮河老街，花一个晚上，赶上"老街电影夜"就搬个小板凳坐街边看一场露天电影，散场在怀旧打卡点拍两张，顺手领一份怀旧零食。免费。想约就说："老街晚上放露天电影，搬个板凳就能看。"

注意每条都含四件东西：**具体地点（可导航）／价格／时段／一句能直接发的话**。少一样就算未完成。

## 为什么不是又一个 date ideas 生成器

| | 通用 date-ideas 项目<br>（Perfect-Date / DateIdeas / Randomizer） | 让大模型直接即兴 | 大众点评榜单 | **LocalDate** |
|---|---|---|---|---|
| 地点真实性 | 欧美通用模板 | 容易编造 | 真实 | 真实，且带来源 |
| 本地化 | 无 | 看模型记不记得 | 强 | 城市包，可自己建 |
| 季节限定事件 | 无 | 偶尔 | 弱 | **独立事件层**（候鸟季/灯会/初雪/草莓期） |
| 记得你的口味 | 无 | 每次重置 | 推荐算法黑箱 | **本地权重文件，可读可改** |
| 输出可直接用 | 一句话点子 | 需要二次加工 | 需要自己排路线 | 时段＋路线＋话术齐备 |
| 数据可审计 | — | — | 闭源 | 每条带来源标记 |

现有开源同类全是欧美模板 + 大模型即兴，**没有一个带本地真实 POI 库、季节限定事件层、和可解释的排序自学习**。这三样是这个项目的差异化。

## 三个核心件

**1. 城市包（City Pack）——真实 POI 库**
一个城市一个目录，表格化：`条目 / 类型 / 适配的核心行为 / 价格 / 来源`。淮南包 800+ 条，全部带来源标记（官方文旅、OTA、地图、媒体报道）。无来源不入库。

**2. 季节限定事件层——"错过等一年"的窗口**
11 月到次年 3 月的小天鹅、落羽杉红叶期、腊月的年货集、正月的灯会、寒潮后的雾凇、12 月开棚的草莓。事件层单独维护，含"预告型"机制：排期没官宣就记账，到点提醒你去。

**3. 排序自学习——你排一次，它学一次**
每轮 15 个方案，你只报数字（"3 4 6 7 8"），系统按 **Bradley-Terry / Elo** 做特征级更新：

```
E = 1 / (1 + 10^((R_opponent - R_self)/400))
R' = R + K × (S - E)                    K = 24, S = 留用1 / 落选0
R_t = R_0 + (R - R_0) × exp(-λ × Δt)    λ = 0.05   # 时间衰减
bonus = c × sqrt(ln N / n_c)            c = 40     # 探索加成
score = Σ w_f × R_f + 0.15 × heat                  # heat = 内容热度
```

落选只**降权**、不封杀：扣到阈值以下且连落两轮才休眠，衰减回升或用一次即复活。避免"一次没选就永久消失"导致供给坍缩。脚本 `tools/score_lite.py` 零依赖可复跑，输入就是你的排序记录。

## 四步上手

1. **装**：把仓库放进 AI 助手的技能目录（WorkBuddy：`~/.workbuddy/skills/localdate/`，Claude Code / Codex 同理），或直接把 `SKILL.md` 内容作为系统指令粘贴。
2. **选包**：`city-packs/huainan/` 是示范包（真实跑过 9 轮）。没有你的城市就复制 `city-pack-template/`，按模板里的搜索清单建库。
3. **用**：说"这周末约会去哪"。
4. **教**：报数字排序。三轮之后权重开始像你。

详见 [`QUICKSTART.md`](QUICKSTART.md)。

## 五条硬规则（框架级，不建议关）

1. **无来源不入库，无搜索不出口**。编造一个店名，整个方案的信任就没了。
2. **门店三件套**：店名 + 可导航地址 + 价格档，缺一不许出口。
3. **营业状态自查**：交付前查近三年（2023-2026）评论/探店/官方报道/地图更新时间，判据优先级＝新近官方媒体 ＞ 地图最近评论 ＞ 近两年探店 ＞ 老攻略；三年无新信息就标"长期无新信息"不出口。**不要把核实的活推给用户。**
4. **每个方案必带一餐**。事前、事中、事后三档挑一个，写进正文（店名＋人均或价位）。没吃的方案算没写完——两个人出门三小时以上不吃东西，那个空档会变成尴尬。
5. **返场上限 1/轮**：同一"场地×核心行为"重复即算返场，全轮最多一个；换时段、换行为、换仪式、换季节到"看起来像另一个项目"的程度，按变体计、不占名额——但必须在正文写出差异点。

另有一条输出侧规则：**术语不出门**。A/B/C/D、权重、慎用检查这些词只存在于内部，给用户看的只有白描句子。

## 贡献一个城市包

欢迎 PR，但标准不低：

1. 复制 `city-pack-template/`，按格式建目录；
2. 每个 POI 必须带来源（官方文旅/OTA/地图/公开报道），**不接受"我记得有家店"**；
3. 至少 100 条 POI、10 条季节限定事件，跑满 3 轮真实排序（含 weights.md 回填记录）；
4. 提交 `examples/<city>-round1.md` 展示一轮真实输出。

**不接受**：爬虫抓来的平台私有数据、无法追溯来源的条目、编造的价格。详见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。

## 反馈闭环：它靠真实使用自己长

不做遥测、不发问卷。**只认一件事：你把上一轮哪几个留下了。**

每轮交付完，技能往 `feedback/feedback.jsonl` 写一行（留了哪些特征、否了哪些、一句备注）：

```bash
python tools/feedback.py add --kept picking,boat --rejected mall --note "草莓棚想再去"
python tools/feedback.py build     # jsonl -> rounds.json，并打印每个特征的升/降
python tools/score_lite.py feedback/rounds.json
```

三条通道，按重量级排：

| 通道 | 用途 |
|---|---|
| 本地 jsonl | 自己用，每轮一行，权重自己会动 |
| `round-feedback` issue | 想让作者把信号并进框架先验（`PRIOR` 表） |
| `venue-report` issue | 店倒了/涨价了/搬了，直接报，别让下一个人白跑 |

为什么不做遥测：城市包里写着"她腰不好""她不喜欢强互动"这类东西，上传就是事故。所以**你主动贴，它不偷偷传**。详见 [`FEEDBACK.md`](FEEDBACK.md)。
