# 数据合规红线（必读）

1. **只许个人内部使用**：收割的探店内容仅用于个人候选参考，不得进入公开发布的城市包、不得转售、不得商用。
2. **不突破反爬**：只用官方客户端登录＋浏览器自动化读公开页；禁止破解签名算法、绕过风控、高频抓取。突破访问控制可能触及《反不正当竞争法》乃至《刑法》第 285 条。
3. **大众点评明确不爬**：判例密集、风险最高。用地图 POI＋OTA＋官方文旅替代。
4. **控制频率**：单关键词 ≤40 条、每天 ≤1 轮，不给平台添负担。
5. **公开发布的库**只准用四类来源：地图/OTA 开放接口、官方文旅公开信息、自主踩点实拍、获授权 UGC。
6. 遵守各平台 Robots 协议与用户协议；平台要求停止时应立即停止。
