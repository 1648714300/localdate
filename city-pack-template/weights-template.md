# 城市包·权重与慎用模板

## 她/他的画像要点（各 5-8 条，生成前加载）
1. 相处母语（平行陪伴/互动型…）→ 决定 A 池排序
2. 亲密节奏慎用 → 身体接触类永不主动排
3. 体力变量 → 高体力项目默认降权
4. 负担感敏感度 → 低解释成本优先
5. 现成梗池 → C 变量可接入的共同话题

## 组合公式
A(核心行为) + B(场地) + C(氛围变量) + D(吃，有且只有一个)

## 配比规则
- 出门节目型 ≤50% + 生活流水型 ≥50%（月度平衡）
- 每轮 15 个 = 10 本地 + 4 近圈(≤1.5h 自驾，仅事件限定) + 1 远途(>3h，仅事件限定)
- 每轮 7 常规 + 2 少去 + 1 慎用（慎用标"先问 TA"）

## 避雷清单（触碰即弃用）
1. 强互动/强制对视型 2. 需要社交的多人局 3. 高体力 4. 重仪式感 5. 单次人均超上限 6. 编造地点 7. 身体亲密推进类安排

## 排序回填记录（追加式）
`第N轮：保=…｜落=…｜特征差=…｜权重改动=…｜黑名单累计=…`

## 三条交付硬规则（框架级，不建议改）
1. 返场上限 1/轮；改变量成"另一个项目"则不计返场（须在正文写出差异）。
2. 营业状态自查：查近三年评论/官方/地图更新时间；三年无新信息不出口。
3. 门店三件套：店名＋地址＋价格，缺一不出。

## v0.4 两条补充
4. 每个方案必带一餐（事前/事中/事后），写店名＋人均；餐饮单独建 `catalog/catalog_food_<城市>.md`，按可信档 A/B/C/D 标注。
5. 返场失效线：同一"场地×核心行为"第 3 次失效，不再占方案位。
